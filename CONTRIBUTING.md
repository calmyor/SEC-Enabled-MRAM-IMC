# Contributing

This repository is a public research artifact. Contributions must preserve technical scope, source provenance, and the distinction among measured, simulated, projected, and synthetic evidence.

## Before opening a change

1. Confirm that you own the material or have explicit redistribution permission.
2. Remove personal information, credentials, machine paths, instrument serial identifiers, supplier/order records, and confidential process detail.
3. Put executable method changes under tests.
4. Bind new measured results to a protocol, data manifest, calibration record, analysis command, and source citation.
5. Label hardware-dependent or unavailable components explicitly; do not imply rebuildability from partial binaries or notebooks.

## Validation

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 examples/protocol_demo.py
corepack enable
pnpm install --frozen-lockfile
pnpm run build
pnpm run validate
```

## Evidence language

- **Measured:** obtained from the fabricated macro under a stated protocol.
- **Simulated:** produced by a behavioral, circuit, or numerical model.
- **Projected:** estimated for a design variant that was not fabricated/measured.
- **Synthetic:** generated by the public educational demo.

Do not broaden a last-layer mapping into a full-network hardware claim, a bank-level SNDR result into universal application accuracy, or a PYNQ binary into a reproducible FPGA build.

## Materials that will not be accepted

- foundry/PDK or validator files;
- GDS/OASIS, unapproved netlists, or raw signoff/waiver output;
- credentials, export paperwork, invoices, airway bills, or personal details;
- large raw captures without a reviewed schema, manifest, license, and archival plan;
- third-party code or figures without redistribution permission; or
- machine-specific notebook dumps presented as a supported interface.
