The complete research arc

The algorithm is only one link in the chain.

The central contribution is a co-design process. Array behavior is modeled, converted into a low-dimensional compensation problem, mapped into fixed-point hardware, integrated with a more stable current sensor, and then evaluated through a purpose-built test stack.

01 · Observe

Model the nonideal array

MTJ variation, line parasitics, read noise, binary column weighting, and ADC quantization expose location-dependent distortion.

02 · Abstract

Factor the error

Per-cell attenuation αᵢⱼ turns an opaque circuit effect into a compensable input/output model.

03 · Co-design

Learn SEC factors

Shared row factors γᵢ and column normalizers θⱼ correct bank-level compute statistics with modest storage.

04 · Realize

Build OCCS + fixed point

Behavioral precision studies select a 7-bit inference scale and 14-bit update path; OCCS reduces readout mismatch.

05 · Measure

Close the silicon loop

Python, PYNQ-Z2, a custom PCB, and code-conditioned sampling reconstruct calibrated SNDR on packaged chips.

Why the problem is hard

A useful signal can be a fraction of one percent.

For a 128-row dot product, the paper’s representative conductance step is 80 μS against a nominal 20 mS column conductance: about 0.4%. Bitline and sourceline voltage gradients, current-sensor noise, column mismatch, and supply drop compete directly with that small step.

80 μS ÷ 20 mS = 0.4%
Scaling changes the design question.

Increasing the dot-product dimension improves parallelism, yet makes adjacent output states harder to distinguish. The project therefore optimizes measurable compute quality—not array density in isolation.

Prototype at a glance

One macro, viewed at four abstraction levels.

The terminology changes with the layer being discussed. Keeping those layers separate prevents several common misreadings of the work.

DEVICE

Physical memory

Commercial 22 nm FD-SOI, 512 × 512 physical 1T1R MRAM cells, operated at 0.8 V.

LOGIC

Signed weight

A differential 2T2R logical representation forms signed 4-bit weights across binary-weighted physical columns.

CIRCUIT

Column conversion

128 ADC columns combine offset-compensated current sensing, a 6-bit SAR ADC, and local control.

ALGORITHM

SEC correction

Learned row scaling and per-column normalization improve task-agnostic bank-level compute SNDR.

What SEC means here

Statistical error compensation.

SEC learns hardware correction factors for the MRAM compute bank. It does not mean single-error correction, does not replace memory ECC, and does not train the application neural network on-chip.

The target is bank-level, task-agnostic compute SNDR. The reported CIFAR-10 experiment maps only the final fully connected layer of ResNet-20 to measured hardware.

Terminology note

The conference paper reports SNR; the expanded journal paper uses SNDR to account for both noise and distortion. This site follows the journal terminology when discussing the full measurement method.
