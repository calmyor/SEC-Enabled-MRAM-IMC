Overview / Measurements

Calibration · sampling · SNDR · application boundary

A measurement is a protocol, not a plotted point.

Compute SNDR must capture both temporal noise and state-dependent distortion over an impossibly large digital state space. The methodology makes that estimation tractable while keeping calibration, sampling, weighting, and repeated trials explicit.

01 · Per-column calibration

Calibrate gain and offset before attributing residual error.

Raw 6-bit ADC output ŷ is mapped to the ideal dot product y₀ with an affine MMSE fit computed off-chip for each physical ADC column. SEC-on evaluation additionally applies the learned output normalization θ.

ỹ = θ(aŷ + b)
Gaina = Cov(y₀, ŷ) / Var(ŷ)
Offsetb = E[y₀] − aE[ŷ]
SEC offθ = 1
SEC onθ includes the SEC output normalization defined for the measured configuration.
Avoid calibration leakage.

Fit a and b on a designated calibration dataset, freeze them, and evaluate SNDR on separately identified measurement records. Store the fit population, column ID, configuration digest, coefficients, units, and analysis commit with every result.

02 · State-space reduction

Sample configurations within every ideal output code.

A binary N-dimensional dot product has 2²ᴺ weight/input configurations. The method groups configurations that yield the same ideal output code c, fixes the weight vector to all ones, randomly selects 30 activation states per code, and repeats every state K = 10 times.

03 · Compute SNDR

Keep the population definition beside the number.

For each ideal code c, the squared residuals of calibrated output ỹ are averaged over sampled states and repeated activations. Column SNDR compares the ideal-output variance with the probability-weighted sum of those code-conditioned errors.

MSEcode(c) = mean[(ỹ − c)²]
SNDRcol = 10 log₁₀ { Var(y₀) / Σc MSEcode(c)P(c) }

Result record must include

  • Dot-product dimension N and reachable code set.
  • Weight policy, state-selection seed, states/code, and repeats/state.
  • ADC precision, column IDs, voltage, clock, and operating mode.
  • Calibration split and per-column gain/offset/normalization.
  • Ideal-code probability model P(c).
  • SEC state/version and whether learning or inference was active.
  • Raw-data and analysis-code checksums.

Application experiment

One measured layer, with a clear boundary.

The CIFAR-10 experiment trains a 4-bit-weight ResNet-20 in software, quantizes 1,000 test inputs to 7 bit, and maps only the final fully connected layer to the measured MRAM macro. It does not map the complete network on-chip and does not use network-specific noise-aware training.

What this supports

The result shows that task-agnostic bank-level SNDR improvement can recover part of the last-layer accuracy loss without network-specific noise-aware training. It does not establish full-network equivalence to digital inference; a material gap remains after SEC.
