Overview / Design

Behavioral model → SEC/OCCS co-design

Start with the error, then design the correction.

The architecture did not begin as a compensation block looking for a use. It began with a behavioral model that showed where each activated row’s contribution is attenuated—and which part of that structure can be shared efficiently in hardware.

01 · Behavioral model

Represent the whole analog path, not an ideal multiply.

The model couples device variation and interconnect to readout and quantization. Its purpose is not transistor-level replacement; it is to expose the dominant error structure quickly enough to explore array size, input ordering, precision, and compensation.

The key observation is spatial.

The same logical activation produces a different analog contribution depending on its physical row. Near- and far-end patterns can bend to opposite sides of the ideal transfer line, with large relative error near a zero-valued dot product.

Model parameters should be interpreted as a calibrated design instrument. Exact foundry device decks and proprietary PDK parameters are intentionally outside the public repository.

02 · Error abstraction

Turn parasitics into factors the architecture can act on.

Let αᵢⱼ describe the attenuation for row i as observed by column j. SEC applies one learned γᵢ to row i across the bank, then normalizes each output column with θⱼ.

yⱼ = Σᵢ θⱼ · γᵢ · αᵢⱼ · wᵢⱼ · xᵢ

αᵢⱼ is the row- and column-dependent attenuation produced by array parasitics. It is a behavioral description of the error, not an extra hardware state.

SHARE

One γ per row

Sharing the input-side correction across ADC columns avoids storing a full correction matrix.

LEARN

Fit the physical die

On-chip stochastic-gradient updates adapt γ to instance-specific parasitics that are unknown before fabrication.

NORMALIZE

One θ per column

Output normalization absorbs column gain so that θⱼγᵢαᵢⱼ approaches unity statistically.

03 · Precision selection

Use convergence studies to freeze the fixed-point path.

Floating-point SEC establishes the algorithmic target. Quantized sweeps then choose widths that preserve convergence while bounding area and switching energy. The implemented inference scale is 7 bit, backed by a 14-bit update accumulator; a power-of-two learning rate enables shift-based updates.

Inference factor7-bit γ path selected from behavioral quantization sweeps.
Update state14-bit accumulator retains the smaller training increments.

ValidationFixed- and floating-point learning trajectories remain closely aligned.
Interpretation“Training” calibrates hardware correction factors; it is not application-model training.

04 · Circuit co-design

Correct the array without ignoring the sensor.

SEC addresses structured array error, but static mismatch and PVT sensitivity in the column sensor can still consume the available signal margin. The offset-compensated current sensor (OCCS) therefore changes both the level-shifting element and the operating sequence.

AUTO-ZERO

Capture static offset

An auto-zero phase stores mismatch before the array current is evaluated.

RESISTIVE SHIFT

Reduce PVT dependence

A resistor replaces the prior transistor level shifter to stabilize the sensing bias.

EVALUATE

Resolve a small current step

The evaluation phase presents an offset-reduced signal to the 6-bit SAR conversion path.

Simulation boundary

The reported 3.8%–8.4% bitline-voltage variation and roughly 17% OCCS area overhead are Monte Carlo circuit-simulation results. They are not direct measurements of the fabricated macro.

05 · Integrated macro

Preserve the signal definition across memory, conversion, and correction.

Each ADC column combines four binary-weighted physical columns. Differential MRAM storage and wordline selection implement signed 1-bit-input × 4-bit-weight operations; multibit activations are evaluated bit-serially.

Design review checklist

Questions that carried from model to layout.

  • Is each modeled nonideality physical, calibrated, and separable from numerical quantization?
  • Does the compensation structure scale with rows and columns more slowly than a full α matrix?
  • Do fixed-point widths preserve convergence across the expected range, not only one seed?
  • Are saturation, rounding, reset, and update ordering defined at bit accuracy?
  • Can the sensor resolve the post-parasitic current step across PVT and mismatch?
  • Are physical 1T1R cells and logical differential 2T2R weights distinguished in verification?
  • Can every internal training and inference mode be reached through the test interface?
  • Does the measurement plan estimate noise and distortion over comparable code populations?
