Design rule for the repository

Every artifact is labeled as public source, sanitized derivative, hardware-dependent, or restricted/unavailable. A file’s presence in the private working archive is not permission to redistribute it.

MeasuredValues reported from the fabricated macro and tied to a paper figure or method.
SimulatedBehavioral/circuit evidence clearly separated from measured silicon.
ProjectedDesign alternatives such as SRAM-based SEC storage, not fabricated claims.
SyntheticToy data produced by the public demonstration package.

Artifact availability

Filter the release boundary.

“Restricted” includes proprietary, identifying, incomplete, or unlicensed material. It describes provenance honestly; it is not an invitation to request foundry-confidential files.

Public source

Measurement-method package

Affine per-column MMSE calibration, deterministic state/repetition sampling, weighted code-conditioned SNDR, and tested result objects.

Public source

An educational multiplicative correction learner with an explicit warning that it is not controller RTL, firmware, or measured data.

Design reasoning, tapeout gates, board review, bring-up ladder, protocol, claim boundaries, citations, and provenance.

Paper figures and board visual

Selected research figures and a final-board rendering, stripped of personal, supplier, and confidential process collateral.

Sanitized derivative

PCB design guide

Public rail/signal, pin-map, revision, and bring-up principles. The older editable TO2/QFN80 source is not mislabeled as the final TO3/QFN64 board.

Sanitized derivative

Tapeout process guide

Newly authored phase and review guidance without foundry rule names, paths, configuration data, waiver details, or release databases.

Restricted / unavailable

ASIC implementation

No public RTL-to-GDS flow is present. PDKs, configuration files, validator material, GDS/OASIS, netlists, raw signoff output, and waivers stay private.

Restricted / unavailable

FPGA rebuild sources

Bit/HWH and notebooks exist, but complete custom RTL, XDC, Vivado project, and build Tcl were not found. No reproducible-overlay claim is made.

Restricted / unavailable

Raw lab archive

Large NPZ/NPY captures, machine-specific paths, instrument identifiers, invoices, airway bills, supplier carts, and unlicensed collaborator code are excluded.

Quick start

Reproduce the public method layer.

The package uses only the Python standard library at runtime. The demo generates toy data locally; it never connects to a board or instrument.

Run the deterministic demonstration

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
python3 examples/protocol_demo.py

Run all tests

PYTHONPATH=src python3 -m unittest \
  discover -s tests -v

Build the website

node scripts/build-site.mjs
Interpret the output correctly.

Protocol counts, fit coefficients, and SNDR values emitted by the demo come from synthetic inputs. The measured 22 nm results on this site come from the ESSCIRC/JSSC record, not from executing the toy example.

Data release pattern

Keep Git small and the dataset inspectable.

The audited archive contains more than one hundred NPZ files, dozens of NPY arrays, duplicates, and individual files tens of megabytes in size. A responsible release requires curation before upload.

01 · SCHEMA

Name every dimension

Units, dtype, shape, code convention, column, chip, mode, clock, voltage, repeat, and missing/fault encoding.

02 · MANIFEST

Bind files to provenance

SHA-256, byte count, acquisition script/commit, overlay hash, board/chip IDs, run time, operator policy, and license.

03 · SAMPLE

Ship a small end-to-end slice

One de-identified representative dataset in Git exercises parsing, calibration, per-code MSE, and plot generation.

04 · ARCHIVE

Deposit approved raw data

Deduplicated full captures belong in a versioned archival release with DOI/checksums, not the Git history.

Contributing

Make additions traceable.

New measured results need the raw-data manifest, protocol parameters, calibration split, analysis command, and evidence class. Hardware assets need ownership approval and a rebuild/version statement. Paper claims need a citation and must retain the scope of the source experiment.

Never commit

Credentials, personal addresses, instrument serial identifiers, commercial invoices, airway bills, PDK/foundry configuration, raw signoff/waiver material, proprietary IP, or third-party code without a redistribution license.
