Quick start

Run the public measurement method.

The deterministic example generates code-conditioned requests, synthetic column responses, per-column calibration, and final weighted SNDR using the Python standard library.

Run the example

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
python3 examples/protocol_demo.py

Run the tests

PYTHONPATH=src python3 -m unittest \
  discover -s tests -v

Build the website

corepack enable
pnpm install --frozen-lockfile
pnpm run build
pnpm run validate
Output labels

Example output is labeled Synthetic; prototype values on the site are labeled Silicon, Circuit simulation, Behavioral model, or Projection.

How to read every number

A compact evidence label identifies the source of each result, while the adjacent condition identifies NNN, ADC columns, clock/precision, sample population, or application mapping.

Data organization

One schema connects a compact sample to full captures.

A small end-to-end dataset belongs in Git for immediate reproduction; versioned full captures belong in DOI-backed archival storage. Both use the same units, dimensions, run fields, configuration digest, and SHA-256 manifest.

01 · SCHEMA

Name every dimension

Code, state, repeat, ADC column, chip, mode, clock, voltage, units, and fault status.

02 · MANIFEST

Bind provenance

SHA-256, acquisition commit, overlay fingerprint, board/chip aliases, timestamp, and license.

03 · SAMPLE

Exercise the full path

Parsing, calibration, per-code MSE, P(c)P(c)P(c) weighting, SNDR, and expected output in one compact fixture.

04 · ARCHIVE

Scale the record

Deduplicated captures, immutable release version, DOI, manifest, and the same analysis command.

Contributing

Make every addition traceable.

A strong contribution connects source, condition, protocol, data, analysis command, and expected result. Hardware additions include their board/overlay identity; numerical additions carry an evidence label and citation.
