Overview / Measurements

Calibration · state sampling · SNDR · application outcome

Compute SNDR separates temporal noise from spatial distortion.

Compute SNDR combines temporal noise and state-dependent distortion. The protocol groups the 2²ᴺ weight/input configurations by ideal code, samples row patterns within each code, and repeats each pattern to estimate both effects.

Raw signalEach ADC column returns codes shaped by gain, offset, noise, and row-dependent distortion.
ProtocolCalibrate per column, sample 30 states per ideal code, and repeat every state 10 times.
MetricWeight code-conditioned residual error by P(c) and compare it with ideal-output variance.

01 · Per-column calibration

Calibrate gain and offset before attributing residual error.

Raw 6-bit ADC output ŷ is mapped to the ideal dot product y₀ with an affine MMSE fit computed off-chip for each physical ADC column. SEC-on evaluation additionally applies the learned output normalization θ.

ỹ = θ(aŷ + b)
Gaina = Cov(y₀, ŷ) / Var(ŷ)
Offsetb = E[y₀] − aE[ŷ]
SEC offθ = 1
SEC onθ includes the SEC output normalization defined for the measured configuration.
Calibration split

Fit a and b on designated calibration records, freeze the coefficients, and compute SNDR on evaluation records. The result retains the fit population, column ID, configuration digest, coefficients, units, and analysis commit.

02 · State-space reduction

Sample configurations within every ideal output code.

A binary N-dimensional dot product has 2²ᴺ weight/input configurations. The method groups configurations that yield the same ideal output code c, fixes the weight vector to all ones, randomly selects 30 activation states per code, and repeats every state K = 10 times.

Why states matter

For a symbolic four-row example, [+ + − −] and [+ − + −] both sum to the ideal code c = 0. They activate different physical row patterns, so their α-weighted array currents—and therefore raw ADC codes—can differ. Sampling 30 states inside one code measures that spatial distortion.

03 · Compute SNDR

Compute one error distribution per ideal code, then weight across codes.

For each ideal code c, squared residuals of calibrated output ỹ are averaged over states and repeats. Column SNDR compares ideal-output variance with the P(c)-weighted sum of those code-conditioned errors.

MSEcode(c) = mean[(ỹ − c)²]
SNDRcol = 10 log₁₀ { Var(y₀) / Σc MSEcode(c)P(c) }

Result record must include

  • Dot-product dimension N and reachable code set.
  • Weight policy, state-selection seed, states/code, and repeats/state.
  • ADC precision, column IDs, voltage, clock, and operating mode.
  • Calibration split and per-column gain/offset/normalization.
  • Ideal-code probability model P(c).
  • SEC state/version and whether learning or inference was active.
  • Raw-data and analysis-code checksums.

Application experiment

SEC recovers 7.2 accuracy points in the measured ResNet-20 output layer.

Software evaluates the convolutional backbone; the macro computes the 4-bit final fully connected layer for 1,000 CIFAR-10 inputs quantized to 7 bits. The same mapping is measured with SEC off and on, with application weights fixed; hardware results report ±5 percentage points at 90% confidence.
