For a symbolic four-row example, x(1)=[+1,+1,−1,−1]\mathbf{x}^{(1)}=[+1,+1,-1,-1]x(1)=[+1,+1,−1,−1] and x(2)=[+1,−1,+1,−1]\mathbf{x}^{(2)}=[+1,-1,+1,-1]x(2)=[+1,−1,+1,−1] both produce the ideal code c=0c=0c=0.
